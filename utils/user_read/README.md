# 用户主页读取

此模块移植自已验证可用的 `DouYin_Spider` 脚本项目，包含用户资料、作品分页、设备号、浏览器指纹、`a_bogus` 和 webSign。代码随当前项目部署，不依赖原项目目录。

`DouyinAPI.get_user_info` 和 `get_user_work_info` 使用此模块；搜索、评论、单作品详情继续使用原有实现。API 从数据库账号池取得认证，先取用户资料，再按 `page_num` 抓取作品并合并作者信息。

- 每个认证对象复用一个 `curl_cffi` 会话和设备号；不同账号独立。
- 签名、查询参数和 User-Agent 使用同一份指纹配置，可通过 `DY_FP_*` 环境变量覆盖。
- 保留原服务的连接/读取超时和 CA 校验配置。
- 作品请求直接发送 webSign 返回的 URL，不能再次传入 `params` 编码。
- 403 仍有限重试；上游列表格式异常返回错误，不伪装为零作品。

签名固定向量由成功项目独立生成，见 `tests/test_user_read.py`。
